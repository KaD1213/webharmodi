# WebHarmoDi.

吹奏楽の合奏指導向け、基準音・ハーモニー・メトロノームのWebアプリです。

## 公開

GitHub Pagesは main ブランチへのpush後、.github/workflows/pages.yml から自動で公開します。リポジトリの Settings → Pages → Build and deployment → Source を GitHub Actions に設定してください。

公開URLは通常 https://<GitHubユーザー名>.github.io/<リポジトリ名>/ です。

アプリは静的ファイルのみで動き、アカウント登録やデータベースは不要です。
