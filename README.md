# WebHarmoDi.

吹奏楽の合奏指導向け、基準音・ハーモニー・メトロノームのWebアプリです。

## 公開

GitHub Pagesは main ブランチへのpush後、.github/workflows/pages.yml から自動で公開します。リポジトリの Settings → Pages → Build and deployment → Source を GitHub Actions に設定してください。

公開URLは通常 https://<GitHubユーザー名>.github.io/<リポジトリ名>/ です。

アプリは静的ファイルのみで動き、アカウント登録やデータベースは不要です。

更新時には `node prepare-release.mjs` で構文・アイコン参照を確認し、内容に応じたキャッシュバージョンを生成します。GitHub Actionsでも公開前に自動実行します。この処理自体は公開を行いません。

## 合奏での使い方

- 基準ピッチは初期値 A = 442 Hz。設定で430〜450 Hzを指定できます。
- 「ドの実音」は C / B♭ / E♭ / F の移調設定です。鍵盤と音域の表示は実際に鳴る音に追従します。
- 平均律／純正律を切り替えられます。純正律の調は実音で指定し、単音はその調の音階、和音は推定したルートを基準に補正します。
- 持続をONにすると、離した鍵盤の音も残ります。同じ鍵盤を押すとその音が止まり、OFFにすると押さえていない音が止まります。
- メトロノームは40〜208 BPM。数値入力とタップは任意の整数、重りと＋／−は実機の目盛り単位です。4分／8分／16分／3連符を選択できます。
- 針はクリック音の再生時刻に同期し、四分音符1拍ごとに左右へ振れます。重りをつかんでいる間は針を固定して調整でき、停止すると中央に戻ります。目盛りの数字は重りの調整中だけ表示します。左右38度の振幅と有限振幅の振り子の運動を用い、折り返しで減速し中央で速くなる動きを描きます。駆動機構は振幅を保つ理想化モデルで、特定の実機と完全に同じ動きを保証するものではありません。端末で動きを減らす設定をしている場合は振幅を小さくします。
- タップは押した瞬間の間隔を測ります。同じ速さでは直近の間隔を平均し、速さを大きく変えた場合は古い間隔を捨てて新しい速さへ追従します。
- 設定はハーモニーとメトロノームで共通です。「音量バランス」を左へ動かすとハーモニー、右へ動かすとメトロノームを強められ、端まで動かすと片方だけになります。中央に戻すボタンもあります。全体の音量は端末側で調整します。
- 音色・音律・移調・調・テンポ・拍数・音量バランス・表示音域・外観は端末内に保存します。発音・再生・持続ONは保存せず、開いた直後に音は鳴りません。
- 共通設定内の「デザイン」で、標準、Studio、Modern、Paperを選べます。各テーマでライト・ダーク・端末に合わせるを指定でき、発音を止めずに切り替えられます。
- キーボードショートカットは A W S E D F T G Y H U J K など。Spaceでメトロノーム、Escで発音とメトロノームを停止します。操作ボタンにフォーカス中のSpaceは、そのボタンの操作を優先します。
- 対応ブラウザでは設定からMIDI入力を接続できます。ノートON/OFF、CC64のサステイン、切断時の停止に対応します。システムエクスクルーシブは要求しません。

## iPhone・オフライン

iPhoneは横向きで利用します。Safariの共有メニューから「ホーム画面に追加」するとアプリとして起動できます。HTTPSまたはlocalhostで開いて設定画面に「オフラインで利用できます」と表示された後は、通信なしでも使えます。オフライン対応やMIDIの可否はブラウザにより異なります。

対応環境では演奏中の画面消灯を防ぎます。別の画面へ移動したり端末をロックしたりすると、発音とメトロノームを停止します。バックグラウンド再生を前提とした設計ではありません。ブラウザの全画面APIが使えない場合は、ホーム画面からの起動方法を表示します。

新しいバージョンが届いても演奏中には自動更新しません。設定画面の「更新を確認」で最新版を取得し、発音とメトロノームを停止してから「更新を適用」を押します。表示中のバージョン番号も設定画面で確認できます。更新ファイルはHTTPキャッシュを避けて一式を取得し、HTMLと同じリリースであることを検証してから保存します。取得失敗時は以前の版を維持します。保存される情報は端末内の設定だけで、アカウントや音声録音、外部への設定送信はありません。

## 音律と音色の範囲

音色はWeb Audioの合成音で、楽器の録音サンプルではありません。Customは準備中のボタンです。純正律は長三度5/4、完全五度3/2、属七の第7音7/4などを用い、転回形と直前の和音からの移動量を考慮します。判別対象外の和音は平均律で鳴らします。2音だけの和音や複雑な和音の解釈は一意ではなく、あらゆる和音のうなりを消すことを保証するものではありません。

ブラウザでのレスポンシブ表示・複数指操作・音程パラメータ・持続解除・保存・メトロノーム・オフラインとサブフォルダ配信を検証しています。iPhone実機の出力音・外部スピーカー・物理MIDI機器での検証は別途必要です。
